El ejercicio del marco de palabras es un reto de manipulación de cadenas que pone a prueba la capacidad de trabajar con longitudes variables y alineación de texto. El objetivo es tomar una frase, dividirla por espacios y presentar cada palabra en su propia línea dentro de un rectángulo de asteriscos cuyo ancho se ajusta automáticamente a la palabra más larga.

## Enunciado

<Note>
Crea una función que reciba un texto y muestre cada palabra en una línea, formando un marco rectangular de asteriscos.

Por ejemplo, con la cadena `"¿Qué te parece el reto?"` el resultado sería:

```
**********
* ¿Qué   *
* te     *
* parece *
* el     *
* reto?  *
**********
```
</Note>

## Enfoque de Solución

El método `longitud` recorre todas las palabras del array y determina la longitud de la más larga añadiendo 2 caracteres (los espacios de relleno). Con ese valor se construye la fila superior e inferior de asteriscos mediante `bases`. Para cada palabra se añade el prefijo `"* "`, se rellena con espacios hasta alcanzar el ancho uniforme y se cierra con `" *"`, consiguiendo así que todas las filas tengan exactamente la misma longitud visible.

## Código Fuente

```csharp title="MarcoPalabras.cs"
/*
  Crea una función que reciba un texto y muestre cada palabra en una línea,
  formando un marco rectangular de asteriscos.

  - ¿Qué te parece el reto? Se vería así:
    **********
    * ¿Qué   *
    * te     *
    * parece *
    * el     *
    * reto?  *
    **********
 */
 
using System;

public class MarcoPalabras
{
    public static void Main(string[] args)
    {
        string cadena = "¿Que te parece el reto?";
        setMarco(cadena.Split(" "));
    }
    
    public static void setMarco(string[] cadena) {
        string marco = ""; 
        
        int lon = longitud(cadena);
        marco = bases(marco, lon);
        marco = marco + "\n";
        
        for(int i = 0; i < cadena.Length; i++){
            cadena[i] = "* " + cadena[i];
            int canEs = (lon) - cadena[i].Length;;
            
            for(int j = 0; j < (canEs); j++) {
                cadena[i] = cadena[i] + " ";
            }
            
            cadena[i] = cadena[i]+" *";
            marco = marco + cadena[i] + "\n";
        }
        
        marco = bases(marco, lon);
        Console.WriteLine(marco);
    }
    
    public static int longitud(string[] cadena) {
        int lon = 0;
        foreach(string palabra in cadena) {
            int len = palabra.Length + 2;
            lon = len > lon ? len : lon;
        }
        return lon;
    }
    
    public static string bases(string marco,int lon) {
         for(int i = 0; i <= lon+1; i++) {
            marco = marco + "*";
        }
        return marco;
    }
}
```

## Conceptos Clave

- **`String.Split`** — divide la cadena de entrada en un array de palabras usando el espacio como separador.
- **Concatenación y relleno de cadenas** — se construye cada fila del marco añadiendo espacios hasta igualar el ancho máximo detectado.
- **Determinación del ancho máximo** — el método `longitud` recorre el array con un `foreach` y compara longitudes para encontrar la palabra más larga.
- **Reutilización de métodos** — `bases` se llama tanto al inicio como al final para generar las líneas horizontales del marco, evitando duplicación de código.
